# ALBUM 02

The second Album for the M-VAVE FM-1: five tracks of filter-house, each patch with its own moving picture.
This is an early build: for now it is fm1-base's template under Album 02's name, without Bluetooth.

Version {{VERSION}}. Installing is at your own risk; the installer can put M-VAVE's own firmware back.

- [Try it in the browser](emu/): the same code the FM-1 runs, with sound. No FM-1 needed.
- [Install](install/): from Chrome or Edge, with the FM-1 connected by USB.
- [Download {{PKG}}](firmware/{{PKG}})
- [Source](https://github.com/joshbartlettband-web/album-02-fm1): MIT. Built on fm1-base (Charles Vestal) and
  felucca-bsp (Leo Kuroshita, Hügelton Instruments).
